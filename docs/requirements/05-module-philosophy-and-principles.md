# 05. Философия и принципы модуля

## Product principles
- **Story-first, issue-later:** сначала фиксация свидетельства, потом агрегация.
- **No evidence loss:** агрегация не уничтожает первичный narrative.
- **Multi-lens clustering:** нет единственного “правильного” кластера.
- **Aggregation without dehumanization:** снижение дублей без потери человеческого слоя.
- **Traceability by design:** любой issue должен быть объясним назад до story.
- **Zero-change SPA:** расширения только опциональные.

## CTO guardrails
- версионируемые правила кластеризации и промоции в issue;
- детерминированный fallback в projection-слое;
- отсутствие фиктивных on-chain полей.

## Decision rules
- если не хватает связности/доказательности -> остаётся cluster analytics;
- если связность есть, но низкая управляемость -> issue-candidate, не issue;
- если нарушается SPA-контракт -> изменение отклоняется для MVP.

## Критерий “правильно спроектировано”
Модуль допускает переосмысление corpus с новыми линзами без миграции/потери первичных свидетельств.

# 08. Distinct Issue: продуктовая логика

## Определение
Distinct issue — агрегированный управляемый кейс, который отражает устойчивый общественный паттерн и имеет доказательную связь с исходными историями.

## Критерии готовности (gate)
- смысловая связность;
- повторяемость/общественная значимость;
- географическая или системная определённость;
- сформулированный desired state;
- честная формулировка без semantic stretch.

## Запрещённые практики
- issue по одному ключевому слову;
- issue “только по эмоции”;
- issue “только по количеству”;
- склейка несовместимых типов сбоев.

## Выходной шаблон issue
- problem title;
- executive summary;
- full narrative context;
- type + labels;
- (опц.) institution;
- evidence linkage.

## Операторские сценарии
- split: широкий candidate распадается на несколько кейсов;
- merge: близкие candidates объединяются в один паттерн;
- reframe: меняется framing без потери lineage.

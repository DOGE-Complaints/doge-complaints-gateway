# 07. Динамические кластеры: продуктовая модель

## Почему dynamic
Фиксированные кластеры рано цементируют смысл и мешают управленческому чтению проблемы с разных сторон.

## Минимальные оси кластеризации (MVP)
- тема;
- география/район;
- тип пространства;
- тип системного сбоя;
- deep need;
- desired state;
- время/повторяемость;
- suggested institution.

## Масштабы
- микро-кейс;
- локальный кластер;
- системный (city-wide) паттерн.

## Обязательные свойства модели
- множественная принадлежность story;
- пересборка по новым критериям;
- различение analytics cluster и issue-ready cluster.

## Выходные артефакты кластера
- доминирующее смысловое ядро;
- narrative-пояснение “что объединяет истории”;
- оценка общественной цены;
- readiness score к issue-candidate.

## Управление качеством
- мониторинг false merge / false split;
- review-процедура для reframe;
- версионирование линз и порогов.

# 01. Миссия модуля

## Product intent
Web2 Core / Story Intelligence Layer — это слой, который превращает поток гражданских narratives в управляемые общественные кейсы без потери человеческого контекста.

## Целевой результат
- сохранить историю как самостоятельный актив (не сырьё для одноразового тикета);
- извлечь сигналы для аналитики и кластеризации;
- сформировать distinct issues, совместимые с текущим SPA;
- подготовить доказательную базу для Web3/внешнего контура.

## Value proposition
- **Для граждан:** история не “стирается” при агрегации.
- **Для операторов:** меньше дублей, выше управляемость backlog.
- **Для продукта:** появляется оперативная память общества, а не просто feed жалоб.

## CTO framing
- Модуль выступает internal source of truth до стадии внешней интеграции.
- Поддерживаются два равноправных слоя: `story truth` и `issue projection truth`.
- Архитектурное ограничение: совместимость с текущим SPA-контрактом без breaking changes.

## KPI верхнего уровня
- доля историй, сохранённых без деградации narrative;
- уровень дедупликации на витринном issue-слое;
- трассируемость `issue -> cluster -> stories` (должна быть 100%);
- time-to-issue-candidate для зрелых кластеров.

## ADR-кандидаты
- ADR-M2-001: Story-first модель как базовый принцип.
- ADR-M2-002: Dynamic clusters вместо фиксированной таксономии.
- ADR-M2-003: Zero-change SPA как контрактное ограничение MVP.

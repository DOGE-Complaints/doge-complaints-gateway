# Module 2 Epic Backlog (Scrum)

## Назначение

Этот каталог содержит epic-level постановку задач для реализации Module 2 на базе утвержденной solution architecture.

Фокус: demo-ready контур с pilot-ready foundations (без включения blockchain runtime в текущем этапе).

Bullrun tracker по этой зоне: `docs/tasks/bullrun-launch-index.md`.

## Стандарт эпика (Scrum)

Каждый epic описан по единому шаблону:
- контекст и бизнес-цель;
- проблема и ожидаемый outcome;
- in scope / out of scope;
- stakeholder map;
- зависимости и предпосылки;
- KPI и критерии успеха;
- acceptance criteria (epic level);
- риски и mitigation;
- Definition of Done;
- стартовая декомпозиция в stories.
